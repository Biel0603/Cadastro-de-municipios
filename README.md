# 🌍 Gestão Territorial - Sistema de Municípios

Este é um projeto **Full Stack** desenvolvido para o gerenciamento de dados geográficos e demográficos de municípios brasileiros. A aplicação permite o controle total de registros (CRUD) em um ambiente dinâmico, utilizando persistência de dados com o banco de dados NoSQL **MongoDB**.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando a stack JavaScript para garantir integração e performance:

- **Frontend:** HTML5, CSS3 (Modern UI) e JavaScript Vanilla.
- **Backend:** Node.js com o framework Express.
- **Banco de Dados:** MongoDB via Mongoose (ODM).

## ✨ Funcionalidades

- **CRUD Completo:** Cadastro, listagem, edição e exclusão de municípios.
- **Busca Instantânea:** Filtro de busca por nome, prefeito ou código IBGE com atualização em tempo real.
- **Filtro por UF:** Seleção rápida para visualizar cidades de estados específicos.
- **Dashboard de Estatísticas:** Painel que calcula automaticamente a população total, área total e quantidade de registros.
- **Interface Responsiva:** Uso de Modais para formulários e Toasts para feedback visual ao usuário.
